# Kairo — Fase A · UX

Fuente de verdad: la especificación del proyecto (prompt inicial). Este documento registra
las decisiones de experiencia que la especificación deja abiertas y verifica que ninguna
rompa las tres restricciones de producto.

## Restricciones no negociables

| Regla | Cómo se cumple |
| --- | --- |
| ≤ 5 acciones primarias globales | Alta rápida · Tareas · Agenda · Filtro de etiquetas · Más |
| Crear exige solo título | El alta rápida es un único campo de texto; no hay otros campos |
| ≤ 3 interacciones, < 10 s | Tocar campo → escribir → Enter. El campo conserva el foco para la siguiente |

## Mapa de navegación

```
Acceso ──(sesión)──▶ AppShell
                     ├── Tareas  (/)            ← pantalla principal
                     │     ├── Alta rápida
                     │     ├── Lista (pendientes → «Completadas» plegable)
                     │     └── Detalle de tarea  (?tarea=<id>)
                     ├── Agenda  (/agenda)
                     │     ├── Hoy          (?rango=hoy, por defecto)
                     │     ├── Esta semana  (?rango=semana)
                     │     └── Detalle de tarea  (?tarea=<id>)
                     └── Más (menú secundario)
                           ├── Cuenta (correo visible en la cabecera del menú)
                           ├── Etiquetas…   → gestor en el panel contextual
                           ├── Exportar JSON
                           ├── Exportar CSV
                           └── Cerrar sesión
```

El filtro de etiquetas es global: se aplica a Tareas y a Agenda y se conserva al cambiar
de vista. El detalle vive en la URL (`?tarea=`) con `history.pushState`, de modo que el
botón «atrás» del sistema cierra el detalle en móvil sin recargar nada.

## Flujos

**Creación.** Foco en el campo → escribir → Enter. La fila entra arriba de la lista
(opacity + translateY, 160 ms). El campo se vacía y conserva el foco. Enter con el campo
vacío no hace nada; si el título supera 140 caracteres el contador aparece al acercarse al
límite (desde 120) y el campo rechaza más texto. Si la red falla, la fila optimista se
retira y aparece un mensaje en línea bajo el campo con la opción de reintentar; el texto
vuelve al campo para no perderlo.

**Edición.** Tocar la fila (fuera del control de completado) abre el detalle.
Escritorio ≥ 1024 px: inspector acoplado a la derecha; la lista sigue visible y la fila
seleccionada queda marcada. < 1024 px: panel que entra desde la derecha (pantalla completa
por debajo de 640 px). Todo se guarda solo: título al salir del campo o tras una pausa,
descripción tras una pausa, fecha/hora/etiquetas al cambiar. Un indicador «Guardado»
discreto confirma en la cabecera del panel. Escape o «atrás» cierra y devuelve el foco a
la fila que lo abrió.

**Eliminación.** Al pie del detalle, «Eliminar tarea» (texto en color de peligro).
Primera pulsación → confirmación en línea («Eliminar» / «Cancelar»). La fila sale de la
lista con un fundido corto y el panel se cierra.

**Completado.** El círculo a la izquierda de cada fila. Marca → trazo del check, tachado
animado, texto en secundario. La fila no se mueve mientras la vista siga montada; al volver
a la vista, las completadas se agrupan en «Completadas», plegado por defecto. El mismo
control revierte.

**Etiquetas.** Se crean desde el detalle de la tarea (escribir un nombre nuevo →
«Crear “…”») o desde Más → Etiquetas. El gestor permite renombrar, cambiar color y
eliminar; eliminar pide confirmación en línea y avisa de que las tareas se conservan.
El color de una etiqueta nueva se asigna automáticamente de una paleta sobria.

**Filtro.** Un único botón «Etiquetas» cerrado por defecto. Popover en escritorio, sheet
inferior en móvil. Selección múltiple; muestra las tareas que tienen *alguna* de las
etiquetas elegidas. Con filtro activo el botón muestra el nombre (o «2 etiquetas») y queda
resaltado; dentro, «Quitar filtro».

**Agenda.** Selector segmentado Hoy / Esta semana dentro de la vista.
- *Hoy*: tareas con fecha de hoy + tareas vencidas pendientes de días anteriores.
- *Esta semana*: hoy y los seis días siguientes (ventana móvil de 7 días, para que un
  domingo no muestre una semana de un solo día) + vencidas pendientes.
- Orden ascendente por fecha y hora; dentro de un día, las tareas sin hora van primero.
- Grupos: «Vencidas», y en la semana un grupo por día («Hoy», «Mañana», «Lunes 14»).
- Las completadas dentro del rango se muestran (para poder revertirlas); las completadas de
  días pasados no.
- Las tareas sin fecha nunca aparecen.

**Exportación.** Más → Exportar JSON / Exportar CSV (2 acciones). El servidor genera el
archivo con el 100 % de las tareas y etiquetas del usuario, independientemente del filtro.

## Escritorio frente a móvil

| | < 640 px | 640–1023 px | ≥ 1024 px |
| --- | --- | --- | --- |
| Navegación | Barra inferior: Tareas · Agenda · Más | Rail de iconos | Rail con etiquetas de texto |
| Detalle | Pantalla que entra desde la derecha | Panel lateral superpuesto | Inspector acoplado |
| Filtro | Sheet inferior | Popover | Popover |
| Más | Sheet inferior | Popover | Popover |
| Gestor de etiquetas | Pantalla completa | Panel lateral | Inspector acoplado |

Ancho máximo de la columna de contenido: 720 px, para que las filas no se estiren en
monitores anchos.
